# TripNest Frontend

Cách chạy:
1. Mở thư mục này bằng VSCode
2. Cài extension "Live Server" (tác giả Ritwick Dey)
3. Chuột phải vào index.html, chọn "Open with Live Server"

Hoặc đơn giản: bấm đúp vào index.html để mở bằng trình duyệt.

Cấu trúc:
- index.html   : khung HTML của trang
- css/style.css: toàn bộ giao diện (màu sắc, bố cục)
- js/data.js   : dữ liệu khách sạn mẫu (sau này thay bằng gọi API backend)
- js/main.js   : logic hiển thị danh sách, bộ chọn số khách
